# FORMA v19 — Greek Deity / Black Marble Edition

## В архиве
- `index.html` — приложение FORMA с дневником, тренировками, питанием и ИИ-тренером из исходной версии.
- `icon-192.png`, `icon-512.png`, `favicon.png` — иконки с головой античного божества и лавровым венком.
- `icon.svg` — векторная вариация эмблемы.
- `manifest.json` — установка приложения на главный экран.
- `sw.js` — сервис-воркер с новой версией кеша.

## Установка
1. Сделайте резервную копию репозитория GitHub.
2. Распакуйте архив и загрузите все файлы в корень репозитория, заменив одноимённые.
3. Нажмите Commit changes и дождитесь публикации GitHub Pages.
4. На iPhone откройте сайт в Safari. Для обновления иконки удалите старый ярлык с экрана «Домой» и добавьте сайт заново.

Не очищайте данные Safari, если хотите сохранить локальный профиль и историю приложения.
