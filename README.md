# FORMA v18 — Black Marble & Gold • Hellenic + AI Coach

## Состав архива
- `index.html` — основное приложение FORMA с чатом ИИ-тренера Никиты.
- `manifest.json` — настройки установки приложения на главный экран.
- `sw.js` — сервис-воркер и обновлённый кеш v18.
- `icon-192.png`, `icon-512.png` — новые чёрно-золотые иконки приложения.
- `favicon.png` — небольшая иконка для вкладки/ярлыка.

## Установка на GitHub Pages
1. Распакуйте архив.
2. Загрузите файлы в корень репозитория, заменив одноимённые файлы.
3. Нажмите **Commit changes** и дождитесь обновления GitHub Pages.
4. Если приложение уже было добавлено на экран «Домой», закройте его и откройте сайт в Safari. При необходимости удалите старый ярлык и добавьте его заново, чтобы обновить иконку.

## ИИ-тренер
Чат использует Cloudflare Worker: `https://forma.4k76hgs96g.workers.dev/`. API-ключ Gemini должен оставаться в секрете Worker Cloudflare, а не в HTML. Предлагаемые изменения дневника применяйте только после проверки карточки подтверждения.

## Важно
Приложение хранит пользовательские данные локально в браузере; не удаляйте данные сайта, если хотите сохранить дневник. Перед заменой файлов полезно сделать копию репозитория.


## Мысль дня
Чередуются стоические высказывания и оригинальные мотивационные строки в эстетике русского и англоязычного рэпа. Строки, помеченные FORMA, являются оригинальными и не приписываются музыкальным исполнителям.
