## Установка
1. Сделай резервную копию текущего репозитория.
2. Распакуй архив и загрузи все файлы в корень GitHub-репозитория, заменив одноимённые.
3. Commit changes и дождись завершения GitHub Pages.
4. Открой сайт и проверь раздел «Никита · ИИ-тренер» → «Проверить связь с Никитой».

Важно: в исходном HTML присутствует URL Worker, но работоспособность внешнего Worker/Gemini зависит от его текущего состояния и квоты. JavaScript проверен на синтаксис; полноценный браузерный тест здесь не выполнялся.
