# FORMA — обновление

## Установка обновления через GitHub на iPhone
1. Скачай и распакуй архив.
2. Открой свой репозиторий GitHub.
3. Add file → Upload files.
4. Загрузи файлы из этой папки в корень репозитория, заменив существующие `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`.
5. Нажми Commit changes.
6. Подожди 1–3 минуты и открой сайт заново. Если старая версия осталась, закрой установленное веб-приложение, открой сайт в Safari и обнови страницу; при необходимости удали FORMA с экрана «Домой» и добавь заново.

## Что добавлено
- Персональный конструктор тренировок: зал / дом / улица, Full body, верх/низ, Push/Pull/Legs и сплит по мышцам.
- Настройки опыта, длительности, частоты, оборудования, фокуса и исключения упражнений через список названий. Можно исключить становую тягу и другие движения.
- Дополнительные упражнения для дома и улицы; техника и доступные замены отображаются в карточках.
- Фильтры кухни: примерный бюджет на порцию, время готовки, острота, тип питания, кухня, сложность, исключаемые продукты и продукты, которые уже есть дома.
- Расширен каталог рецептов; настройки кухни сохраняются на этом устройстве.
- Уменьшение воды кнопкой −250 мл; объём не уходит ниже нуля.
- Расширенная библиотека упражнений.
- Сохранение и загрузка собственных тренировок.
- После замены упражнения отображается техника выбранного упражнения, если оно есть в библиотеке; для прочих вариантов есть безопасная общая инструкция.
- Отдельная вкладка «Кухня»: конструктор блюда, тип приёма пищи, время, рецепты и добавление рецепта в дневник КБЖУ.
- Возможность создавать собственные рецепты.

## Важно
Данные остаются локальными в браузере через localStorage. Перед крупными обновлениями экспортируй JSON в разделе «Профиль». КБЖУ и цены рецептов — ориентировочные, уточняй состав и граммовки. Фильтры и генерация тренировок — эвристические подсказки, не медицинская оценка; при боли или травме не используй движение без консультации специалиста. Не реализованы реальные аккаунты, синхронизация, серверный ИИ и push-уведомления.
