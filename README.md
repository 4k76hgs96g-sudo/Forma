# FORMA — публикация на GitHub Pages

## Файлы
- `index.html` — приложение (HTML, CSS и JavaScript в одном файле)
- `manifest.json` — настройки установки как веб-приложения
- `sw.js` — базовое кеширование для офлайн-открытия
- `icon-192.png`, `icon-512.png` — иконки

## Публикация
1. Создайте публичный репозиторий GitHub, например `forma-app`.
2. Внутри репозитория загрузите ВСЕ пять файлов в корень (не только ZIP).
3. Откройте Settings → Pages.
4. В Build and deployment выберите Deploy from a branch.
5. Branch: `main`, folder: `/(root)`, затем Save.
6. Подождите, пока GitHub Pages опубликует сайт. Адрес будет похож на `https://ВАШ-ЛОГИН.github.io/forma-app/`.
7. Откройте адрес в Safari на iPhone → кнопка «Поделиться» → «На экран Домой».

## Ограничения текущей версии
- Данные хранятся локально в браузере на этом устройстве; общего аккаунта/синхронизации между друзьями нет.
- Чат-помощник не подключён к API: он помогает подготовить запрос и скопировать его в ChatGPT.
- Добавки можно отмечать по расписанию, но push-уведомления при закрытом приложении не настроены.
- База КБЖУ примерная. Сверяйте значения с упаковкой и учитывайте сырой/готовый вес.
- Не вводите секретные данные. Для настоящих аккаунтов, общего рейтинга, AI и надёжных push-уведомлений понадобится backend.
