# FORMA v13 — Black & Gold + Cardio

## Что обновлено
- Премиальная тёмная палитра с золотыми акцентами, обновлённые иконки приложения и навигации.
- Более выразительные интерактивные карточки мышечных групп.
- Расширенная библиотека упражнений для груди, спины, плеч, рук, пресса, ног, предплечий и Full body; добавлены комплексные варианты для разных условий.
- Добавлена отдельная вкладка кардио: таймер, GPS-маршрут для бега/ходьбы/других занятий, дистанция, средняя скорость и приблизительный расход калорий.
- Объединены дневник КБЖУ и кухня в одной вкладке «Еда».
- При открытии упражнения показывается окно с техникой, ключевыми подсказками и схематичной иллюстрацией движения.
- Замена упражнений через поиск и выбор из списка той же мышечной группы.
- Исключение упражнений через поиск и переключаемые элементы, без ручного ввода названий.
- Существенно расширенная офлайн-база продуктов, готовых блюд и ориентировочных карточек товаров магазинов.
- Брендовые и магазинные записи не синхронизируются с магазинами; значения КБЖУ примерные, нужно проверять упаковку.

## Установка
Замените в корне GitHub-репозитория все файлы из архива: `index.html`, `sw.js`, `manifest.json`, `icon-192.png`, `icon-512.png`, `README.md`. Затем выполните Commit changes и дождитесь обновления GitHub Pages.

- GPS работает только при разрешённой геолокации и обычно требует HTTPS; браузер может приостанавливать запись в фоне. Калории — приблизительная оценка по MET и весу.

## Важные ограничения
- Иллюстрация упражнения — схематическая, а не фото/видео конкретного движения. Техника содержит общие ориентиры; для сложных движений нужно сверяться с квалифицированным тренером.
- КБЖУ товаров и блюд в офлайн-базе ориентировочные, не являются проверенными данными конкретной партии/упаковки.
