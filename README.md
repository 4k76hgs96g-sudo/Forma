# FORMA — обновление интерфейса и баз

## Что обновлено
- Премиальная палитра: чёрный, золото и оливково-болотный.
- Нижняя навигация приведена к единой системе иконок с золотыми рамками и активным состоянием.
- Карточка рецепта открывает подробный экран: КБЖУ, порция, стоимость и время, ингредиенты, шаги приготовления, добавление в дневник.
- Каталог расширен примерно до 100 вариантов упражнений и 40 рецептов.
- При замене упражнения приложение использует технику из каталога; для пользовательского названия выдаёт инструкции по соответствующей группе мышц, чтобы поле техники не оставалось пустым.
- Обновлён ключ кэша Service Worker для загрузки новой оболочки.

## Установка
Загрузи `index.html`, `sw.js`, `manifest.json`, `icon-192.png` и `icon-512.png` в корень GitHub Pages репозитория и подтверди замену одноимённых файлов. Затем открой сайт в Safari и обнови его.

## Примечания
Рецепты и макросы ориентировочные, цены приблизительные. Приложение остаётся статическим сайтом; данные хранятся локально на устройстве. JavaScript проверен на синтаксис, но интерфейс следует дополнительно проверить в мобильном Safari после публикации.


## FORMA v6
- При первом запуске появляется анкета профиля; нормы калорий, БЖУ и воды рассчитываются по возрасту, полу, росту, весу, активности и цели.
- Внизу главного экрана есть сброс с повторным заполнением анкеты. Сброс удаляет локальные записи, сохранённые планы и прогресс.
- При каждом открытии страницы показывается новая цитата стоика.
- Главный экран упрощён под компактную инфографику, нижние иконки приведены к единому SVG-стилю.
- Добавлены упражнения и рецепты.
